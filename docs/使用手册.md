# 快捷方式面板 · 使用手册

把常用的程序、文件、文件夹、网址收进一个宫格面板，随手就能点到。
支持文件夹分组、侧边栏分类、图标自由尺寸、搜索直达，所有数据都存在你自己的电脑上。

- 平台：Windows
- 版本：1.8.0
- 仓库：https://github.com/Miao-a123/utools-shortcut-launcher

---

## 一、快速上手

### 1. 打开面板

在 uTools 搜索框输入 `快捷方式`、`快捷启动` 或 `快捷面板`，回车即可打开。
中文关键词自动支持拼音和首字母，例如输入 `kjfs` 也能匹配到。

> 建议在 uTools 里把「快捷方式」固定到搜索框或超级面板，以后一键就能打开。

### 2. 添加图标

四种方式，任选一种：

| 方式 | 操作 |
| --- | --- |
| 拖拽 | 直接把文件 / 文件夹 / 桌面快捷方式拖进面板窗口，松手即添加 |
| 工具栏「添加」 | 点击右上角 **添加** 按钮 → 选择「添加文件 / 文件夹…」或「添加网址…」 |
| 从剪贴板 | 添加 → 「从剪贴板添加」，读取剪贴板里的文件或网址 |
| uTools 搜索框 | 选中文件后在 uTools 里触发「添加为快捷方式」；输入网址时触发「添加网址为快捷方式」 |

底部还提供两个批量入口：

- **扫描本机应用…** —— 从开始菜单、桌面、注册表、应用列表中批量扫描已安装程序，勾选后一次性加入
- **导入浏览器收藏夹…** —— 读取 Chrome / Edge 等 Chromium 系浏览器的收藏夹，按文件夹勾选导入

### 3. 打开与编辑

- **打开**：单击图标即可（可在设置里改成双击）
- **右键图标**：编辑、改图标、改尺寸、移动到分类、装进文件夹、删除
- **拖动图标**：调整位置；拖到侧边栏某个分类上可快速归类

## 二、文件夹与大文件夹

文件夹和大文件夹是**同一个东西的两种形态**，区别只在尺寸：

| 形态 | 尺寸 | 行为 |
| --- | --- | --- |
| 小文件夹 | 1 × 1 | 点击后在弹层里查看和操作里面的图标 |
| 大文件夹 | m × n | 里面的图标直接平铺显示，可直接点击启动 |

### 怎么用

1. **新建**：工具栏「添加」→「新建文件夹」，或在面板空白处右键 →「新建文件夹」；也可以多选若干图标后点「装进文件夹」一键创建
2. **放进去**：把图标直接拖到文件夹上（会高亮提示），松手即放入
3. **拿出来**：在大文件夹里把图标拖到面板空白处即移出；也可以右键 →「移出文件夹」
4. **改尺寸**：右键文件夹 →「尺寸」，1×1 是小文件夹，调大成 2×2、3×2 等就变成大文件夹
5. **改外观**：右键文件夹 →「重命名」/「颜色」，可设置名称与背景色
6. **解散**：右键 →「解散文件夹」，里面的图标全部回到主面板

### 大文件夹的几个贴心设计

- **名称在文件夹下方**：文件夹的名字和数量跟图标名称一样画在格子下方（因此也跟图标名称同一套显隐逻辑 —— 关掉「图标文字」时它会一起隐藏，这时把鼠标停在文件夹上会弹名称气泡）
- **内部不显示图标名称**：大文件夹里只放图标 —— 那里空间小，名称会盖住图标，也会白占近四分之一的高度。想知道某个图标叫什么，**把鼠标停在它上面**，光标旁边会弹出名称气泡
- **整页翻动**：图标放得多、一屏放不下时，鼠标停在大文件夹里滚动滚轮就会翻页 —— 每页都是完整的整行，图标永远不会停在"裁掉半截"的位置。翻到第一页 / 最后一页之后，滚轮会交还给外层页面继续滚
- **没有页标**：右下角**不会**出现「‹ 1/2 ›」这类页码控件 —— 图标区一点都不能被占（曾经有过一版，某些尺寸下会压到图标）
- **点空白处就能打开**：点大文件夹的**任意空白处**（图标之间的空隙、四周留白、下方的名称）就会打开弹层，一次看全所有图标
- **点图标是启动**：大文件夹里点图标本身 = 直接启动它，不会打开文件夹

### 名称画在哪里

名称不占格子内部的空间 —— 它画在**格子下方**的空白里。所以：

- **图标和格子的大小是固定的**，不会因为显示名称而缩小（以前有字模式下图标要为两行文字让位，会小一圈）
- 显示名称时，**每一行格子之间的距离会自动加大**，把名称的位置留出来；关掉名称，行距就收回，面板更紧凑
- 名称最多显示两行，超出的部分省略号截断；每行都按两行的高度预留，所以行与行之间永远是均匀的

**特殊情况：格子被拉成竖条 / 横条时**，图标不再居中（居中的话两边会空一大片），而是按 1×1 的大小贴到一边。同时格子里会**额外显示一份名称**，填在空出来的那块地方：

| 格子形状 | 图标位置 | 格子内名称 | 格子下方名称 |
| --- | --- | --- | --- |
| 竖条（1 列 × 多行） | 贴**顶** | 图标**下方**，**常驻显示** | 同所有图标（跟着「图标文字」开关） |
| 横条（多列 × 1 行） | 贴**左** | 图标**右侧**，**常驻显示** | 同上 |
| 正方形（1×1、2×2 …） | 居中 | 不显示 | 同上 |

**格子里那份名称不受「图标文字」开关影响** —— 即使关掉名称（无字模式）它也会显示出来。这是有意为之：格子拉这么大却看不出是什么，只能靠悬浮气泡实在太别扭。而格子下方那份名称完全照旧，关掉开关它就隐藏。

图标位置和那份常驻名称只跟**格子形状**有关，跟开关无关 —— 所以关掉名称时，图标依然贴在那一侧。

### 内部显示方式：图标 / 列表

每个大文件夹可以**单独**决定里面怎么排（右键文件夹 →「内部显示方式」）：

| 方式 | 长什么样 | 适合 |
| --- | --- | --- |
| **图标**（默认） | 小图标平铺成多列，名称靠鼠标悬浮气泡 | 一堆程序，认图标就够 |
| **列表** | 一行一个，图标缩小贴左、**名称写在右边** | 一堆文档 / 脚本，需要看名字 |

- 这个设置**只影响该文件夹**，别的文件夹各管各的
- 列表模式下行高比图标模式矮，一页能放的行数按文件夹高度自动算；放不下照样滚轮翻页
- 1×1 的小文件夹不展示内部，所以没有这个选项

### 文件夹里的图标大小

设置 →「文件夹内图标大小」可选 **小 / 中 / 大 / 与主格一致**。

这个档位决定的是**内部格子的边长**（相对主格子：55% / 75% / 95% / 100%），图标再按**格子边长的 72%** 显示（和主网格用的是同一个比例），所以里面不会出现"格子箍着图标"的拥挤感；选「与主格一致」时，里面的格子和图标跟外面**完全一样大**。

同一个文件夹里，系统会为当前尺寸和图标数量挑一种**最匀称的摆法**（依次比较占用面积和末行填充率），必要时把格子缩到档位的 78% 来换取更整齐的排布 —— 所以同一个档位下，图标在空间紧张的大文件夹里可能略小一点点，但换来的是四周留白对称、末行不瘪、图标不会被裁掉边缘。

这个设置只决定文件夹内部的大小，与文件夹本身的尺寸无关。

## 三、多选与批量操作

- **框选**：在面板空白处按住鼠标拖动，画出一个框，框住的图标会被选中；按住 `Ctrl` 可追加选择
- **全选**：`Ctrl + A`
- **批量菜单**（右键任意选中项，或用底部批量条）：打开全部、移动到分类、装进文件夹、改图标尺寸、刷新图标、删除

---

## 四、分类与排序

- 左侧边栏底部是分类列表，点 **+** 新建分类，右键分类可重命名 / 改颜色 / 删除
- 把图标拖到某个分类上即可归类；多选后拖过去可批量归类
- 「全部」显示所有顶层图标，「未分类」只显示没有归类的
- 右上角「排序」可切换：手动排序（拖拽调整）、按名称、按创建时间、按最近使用

> 侧边栏的宽度可以直接拖动它右侧边缘调整，也可以在设置里用滑块调。

## 五、图标

### 图标是怎么来的

添加时插件会自动从原文件里提取图标并归一化处理（裁掉透明留白、等比铺满），所以不同来源的图标看起来大小一致。

- **网址类**：优先读取网页里声明的图标，其次尝试站点根目录的 `favicon.ico`
- **程序 / 文件类**：从 exe / 快捷方式里提取

### 手动换图标

右键图标 →「编辑」/「更换图标」，可以：

- 从本地选一张图片作为图标
- 输入一个字母 + 背景色，生成字母图标
- 重新提取原文件图标

### 图标显示不出来？

设置 →「图标」→ 点 **重建全部图标**，会按当前规则重新提取所有图标。
个别应用本身不提供图标文件时会自动退回字形图标，属正常现象。

## 六、外观设置

设置面板从**左下角**弹出，不会挡住你的图标。

| 项目 | 说明 |
| --- | --- |
| 图标文字 | 显示 / 隐藏名称。名称画在**格子下方**：显示时每一行之间会自动加大距离，隐藏时行距收回、改由鼠标悬浮气泡显示名字。文件夹的名字也走这一套；大文件夹内部的图标例外（那里的名称本来就不显示） |
| 自动对齐 | **自动补齐**（默认）：图标总是往上挤紧，不留空位；**自由摆放**：可以把图标放到任意空格，拖动后原地留空 |
| 图标格子大小 | 64 – 160 px，实时预览 |
| 侧边栏宽度 | 120 – 420 px |
| 图标圆角 | 4 – 24 px |
| 文件夹内图标大小 | 小 / 中 / 大 / 与主格一致 |
| 图标格子背景 | 从 10 个预设色里选，或用取色器自定义；下方滑块调**不透明度**（0% 全透明，100% 完全不透明） |
| 图标格子描边 | 先选颜色，再选粗细（1 / 2 / 3 px）；留空即无描边 |

> 「图标圆角 / 图标格子背景 / 图标格子描边」这三项**对文件夹内部的图标同样生效** —— 里面和外面用同一套外观，看起来才是一体的。
| 主题 | 跟随 uTools / 深色 / 浅色 |
| 打开方式 | 单击打开 / 双击打开 |
| 打开快捷方式后 | 隐藏面板 / 保留面板 |
| 删除快捷方式 | 删除前确认 / 直接删除 |
| 浏览器图标 | **联网获取**（默认）：新建网址快捷方式时抓取网站图标；**仅本地**：完全不联网，网址图标改用快捷方式自带的图标文件或字形图标 |

### 小技巧

打开插件后**直接敲键盘**就会进入搜索框，不用先用鼠标点。

**隐藏图标文字之后认不出是哪个图标？** 把鼠标停在图标上，光标旁边会弹出一个小气泡显示它的名称 —— 气泡跟着鼠标走，贴着窗口右边或下边时会自动翻到另一侧，不会跑出窗口；按住鼠标拖拽、框选或拉大小的时候不会弹，免得挡视线。

**想把图标摆成自己的布局？** 设置里把「自动对齐」切成**自由摆放**。之后拖动图标会出现一个虚线格子提示落点，松手就停在那格；原来的位置空着、不会再被后面的图标补上。落点已经被别的图标占了的话会自动挪到最近的空位，不会互相压住。想恢复紧凑排布，切回「自动补齐」就行 —— 你摆好的位置会记着，再切回自由摆放还是原样。

**想把几个图标整体挪个地方？** 在自由摆放下按住 `Ctrl` 点选（或框选）几个图标，然后拖着其中任意一个走 —— 整组会保持它们之间的相对位置一起平移过去，中间的间隔也照样保留，原来的位置空着。拖动时那一组虚线格子就是它们将要落到的地方。

## 七、搜索

顶部搜索框支持按**名称**、**目标路径**、**备注**模糊搜索。
如果命中的图标在某个文件夹里，对应的文件夹会自动一起显示出来。

- `Ctrl + F` 聚焦搜索框
- 搜索框里按 `Esc` 清空搜索
- 只有一个结果时按回车直接打开

## 八、数据

所有数据保存在本机，不会上传：

```
%APPDATA%\uTools\shortcut-launcher\
├── data.json     你的快捷方式、文件夹、分类与全部设置
├── plugin.log    运行日志（超过 512 KB 自动清空）
└── tmp\          图标提取时用的临时文件
```

也可以在设置 →「数据」里：

- **打开数据目录** —— 直接在资源管理器里定位
- **导出数据** —— 存成一份 JSON 备份
- **导入数据** —— 支持「合并」（追加）和「覆盖」（完全替换）
- **清空全部数据** —— 谨慎使用，建议先导出备份

> 因为数据存在本地文件而不是 uTools 数据库里，所以**不会跟随 uTools 账号在多台电脑间同步**。
> 换电脑时用「导出数据」→「导入数据」迁移。

## 九、常见问题

**Q：拖进去的图标打不开，提示目标为空？**
A：多半是原快捷方式的目标已失效。右键 →「编辑」重新指定目标路径即可。

**Q：微信小程序、`weixin://` 这类自定义协议的快捷方式能加吗？**
A：可以。插件会从快捷方式里解析出内嵌的协议地址，点击时交给系统处理。

**Q：图标显示得比其他图标小？**
A：设置 →「重建全部图标」刷新一遍即可，插件会重新裁掉透明留白。

**Q：能装在 macOS / Linux 上吗？**
A：暂时不行。快捷方式解析和图标提取依赖 Windows 的 PowerShell，目前只支持 Windows。
