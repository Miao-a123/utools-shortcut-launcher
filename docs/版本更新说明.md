## v1.8.4（2026-10-22）

**修复几处会被用户直接碰到的问题，并改善拖动设置时的流畅度。**

- **修复（重要）**：搜索或切换分类后，之前选中的图标仍算在「已选」里 —— 屏幕上看不见它们，但右键「删除 N 项」会把它们一起删掉。现在选择范围会自动收窄到当前屏幕上真正看得见的那些。
- 修复：选中文件夹后点「刷新图标」，文件夹标题旁的数量会消失。
- 修复：文件夹名字里如果带 HTML 代码（例如从浏览器收藏夹导入的书签标题），会被当成网页代码执行；现在一律按纯文本显示。
- 修复：大文件夹内部把图标拖大时，可能撑出文件夹边界被裁掉一半；现在按文件夹内部的实际列数限制。
- 修复：关闭「图标文字」后，被拉长的格子（竖条 / 横条）里图标和格内名称会贴在一起。
- 修复：文件夹内部的图标以前检测不到「目标已失效」，红点只在主面板生效；现在里面也会标红点。
- 修复：鼠标在窗口外松开时，拖拽调整尺寸的状态会卡住 —— 之后只是移动鼠标，图标大小就跟着变。
- 改善：拖动设置里的滑块（格子大小、圆角、背景不透明度等）不再每次都整屏重建；批量改尺寸 / 改分类也从「改几个重建几次」变成只重建一次。
- 修复：窗口尺寸变化后，自由摆放模式下图标可能横向溢出，现在会自动重排。
- 美化：被拉长的格子里那份名称改用更柔和的次要色、贴合图标排布，看起来像图标自己的说明文字，不再和格子下方的名称抢戏。

## v1.8.3（2026-10-22）

**文档与说明的一致性修正（主要影响「使用手册」的正确性）。**

- 修复：使用手册「外观设置」那张表有一半渲染不出来（表格中间被一段提示语隔断），现已补全，并补上此前漏掉的设置项。
- 修复：使用手册里几处操作说明写错了位置 —— 「扫描本机应用 / 导入浏览器收藏夹」在右上角「添加」菜单里（不在底部）、「装进文件夹」只在底部批量条上（右键批量菜单里没有）、新建分类的「+」在侧边栏顶部；另有几处右键菜单项名称与实际不符。
- 改进：导入浏览器收藏夹时，文件夹的勾选框会显示**半选**状态（已选几个 / 共几个），以前部分勾选时看起来和完全没选一样。
- 修复：发布检查脚本宣称会检查 sourcemap 文件、实际没有这条规则，现已补上。

## v1.8.2（2026-10-22）

**安全与稳定性加固。**

- 安全修复：去掉了一处可能被利用来执行任意命令的回退逻辑（打开网址失败时曾经绕道系统的命令行解释器，而网址、文件路径里的特殊字符会被重新解析）。现在打开失败就如实报错，不再绕路。
- 修复：数据文件万一损坏（断电、强制结束进程等），以前会静默变成空面板，随手操作一下就把真实数据覆盖没了。现在会**备份损坏的文件、进入只读保护并明确提示备份位置** —— 不会再覆盖。
- 修复：改进了「读取本地图片当图标」的检查，不再可能被用来读非图片文件。
- 修复：抓取网站图标时会拒绝指向本机 / 内网地址的请求。
- 修复：调用系统组件失败时（例如被安全软件拦截）现在会明确提示失败，而不是显示「完成，0 项」。
- 修复：插件关闭时会一并结束后台进程，不再残留。
- 修复：日志写满后改为保留上一份再开新文件，不再清空历史。

## v1.8.0（2026-10-17）

**本次上架的主版本，包含界面与交互的主要改进。**

- **图标名称画到格子下方**：图标和格子大小不再随「显示 / 隐藏名称」变化；显示名称时自动加大行距，名称写在格子下方，更清爽。
- 文件夹的标题与图标名称统一为同一套显示逻辑（同样画在格子下方、同样受名称开关控制，多带一个数量）。
- **大文件夹内容整页翻动**：每页都是完整整行，不会出现图标被裁掉半截；滚轮翻页，翻到头把滚轮让回页面，且**不占用图标区**（没有任何页码控件）。
- 大文件夹内部不显示图标名称（空间小，名称会盖住图标），把鼠标停在图标上即可看到名字。
- 点大文件夹的**任意空白处**即可打开弹层，一次看全所有图标。
- 每个大文件夹可**单独**设置「内部显示方式」：图标（平铺）或列表（一行一个、名称写在右边，适合装文档）。
- 大文件夹内部的空间利用做了优化：先挑图标最大的摆法、一样大时挑最匀称的，内容居中、四周留白对称，任何尺寸下都不会越界被裁。
- 数量凑不满整行时，剩下的图标会**居中**摆放。
- 大文件夹内部的格子也带上格子背景、描边和圆角，和外面共用同一套外观设置。
- 格子被拉成 **1×n / n×1**（竖条 / 横条）时，图标贴上 / 左，空出来的地方再显示一份名称。
- 修复：大文件夹切成「列表」后重新进入插件会变回图标形态（字段保存时漏了一项）。

## 上架信息（供填写市场页面）

- **插件名称**：快捷方式面板
- **一句话介绍**：把常用程序、文件、文件夹、网址收进一个可分类、可自由调整尺寸的宫格面板，从 uTools 搜索框直达。
- **平台**：Windows
- **主要亮点**：
  - 三种添加方式（拖拽 / 手动 / 剪贴板），自动获取高清图标
  - 侧边栏分类 + 宫格自由布局（图标可占 1×1 ～ 4×4）
  - 文件夹 / 大文件夹（图标平铺或列表两种内部形态）
  - 一键扫描本机应用、导入浏览器收藏夹
  - 外观可调（格子大小 / 圆角 / 背景 / 描边 / 名称显隐）
  - 全局搜索（`Ctrl+F`，打开即可直接键入）、浅色 / 深色跟随 uTools
